## 文件与打开方式

- [v0.2 本地预览页](../UI界面/修订_v0.2/预览.html)：十四张画板，可点击工作台入口 → 买方／卖方列表 → 订单详情；可勾选“显示跳转区域”。业务接受、付款、同意取消等不执行真实交易。支持缩放和键盘切换，无需登录或联网，请保留同目录 PNG。
- `修订_v0.2/*.svg`：可导入的矢量画板，保留文字和形状。导入 Pixso 后文字、图层和字体仍需实际核对。
- `修订_v0.2/画板清单.json`：画板编号、尺寸、PNG/SVG 路径及本地预览跳转区域。SVG 本身不携带这些原型连线。
- `../UI界面/修订_v0.2/*.png`：2 倍分辨率的本地预览。
- `生成初稿.py`：v0.1 生成脚本，不改写已有初稿。
- `生成修订稿.py`：复用初稿绘图方法，仅写入 v0.2 目录；Python 标准库即可运行，同时生成离线预览 HTML。
- `导出预览.cjs`：使用 sharp 渲染 PNG，不操作 Pixso。第二个命令行参数为可选 Node.js 包目录，第三个为版本目录，省略版本时仍导出 v0.1。
- `整理界面图片.py`：按画板清单顺序将完整 PNG 无损复制为 `UI界面/界面1.png` 等，并生成编号目录；不改变图片尺寸，也不截图浏览器工具栏。
- [v0.1 原稿预览](../UI界面/初稿_v0.1/预览.html)：十张原始画板、源文件与预览均保留，供对照审查。
- `../UI设计说明.md`：页面说明、模块覆盖和后续工作。

生成修订素材：`python 生成修订稿.py`；导出：`node 导出预览.cjs "已安装 sharp 的 node_modules 绝对路径" 修订_v0.2`。脚本从自身所在目录解析仓库路径。

## 导入 Pixso 并形成工具内源稿

1. 在 Pixso 工作台的个人草稿内使用“导入文件”，选取本目录中的 SVG；也可进入设计文件，将 SVG 拖到画布。
2. 先导入 `UI-02_商品浏览.svg`，核对画板尺寸、中文字体、按钮和图片；确认能继续编辑后再导入其他画板。各 SVG 均为独立画板，不需要导入 PNG。
3. 字体使用 Microsoft YaHei；若提示缺失，使用工具内可用的中文无衬线字体统一替换，并检查换行和对齐。不要把整页作为一张位图粘贴后视为完成可编辑源稿。
4. 在工具内按“商品浏览、商品详情、发布、工作台、买卖列表、订单与状态变体”整理画板，补充“修改方案”弹窗及原型连线。本地 HTML 的跳转区域不会随 SVG 自动导入。
5. 保存设计文件，记录实际项目链接；从 Pixso 导出 2x PNG 和工具支持的本地完整设计文件，另存下一版本。工具内修改需要同步到本仓库，不能让本地预览与工具内画板长期分离。
6. 核对无缺字、错位、截断及比例变化后，再标记“已在 Pixso 核对”。本文件不预填项目链接或核对结论。

官方说明：[导入文件](https://pixso.cn/help/guide/8/1660225022876517/)、[导出文件](https://pixso.cn/help/guide/8/1660225022876746/)。
