## 文件与打开方式

- `初稿_v0.1/*.svg`：可导入的矢量画板，保留文字和形状，未将整页扁平化为图片。可用浏览器直接查看；导入 Pixso 后文字、图层组织及字体效果仍需实际核对。
- `初稿_v0.1/画板清单.json`：画板编号、标题、尺寸、SVG 与 PNG 的对应关系。
- `../UI界面/初稿_v0.1/*.png`：2 倍分辨率的本地预览，供讨论使用。
- `生成初稿.py`：生成 SVG 的辅助脚本，Python 标准库即可运行。
- `导出预览.cjs`：使用 sharp 渲染本地预览，不操作 Pixso。第二个命令行参数可指定安装 sharp 的 Node.js 包目录。
- `../UI设计说明.md`：页面说明、模块覆盖和后续工作。

## 导入 Pixso 并形成工具内源稿

1. 在 Pixso 工作台的个人草稿内使用“导入文件”，选取本目录中的 SVG；也可进入设计文件，将 SVG 拖到画布。
2. 先导入 `UI-02_商品浏览.svg`，核对画板尺寸、中文字体、按钮和图片；确认能继续编辑后再导入其他画板。各 SVG 均为独立画板，不需要导入 PNG。
3. 字体使用 Microsoft YaHei；若提示缺失，使用工具内可用的中文无衬线字体统一替换，并检查换行和对齐。不要把整页作为一张位图粘贴后视为完成可编辑源稿。
4. 在工具内按“商品浏览、商品详情、发布、工作台、订单与状态变体”整理画板，补充“修改方案”弹窗及预约反馈的原型连线。静态 SVG 不携带可执行原型。
5. 保存设计文件，记录实际项目链接；从 Pixso 导出 2x PNG 和工具支持的本地完整设计文件，另存下一版本。工具内修改需要同步到本仓库，不能让本地预览与工具内画板长期分离。
6. 核对无缺字、错位、截断及比例变化后，再标记“已在 Pixso 核对”。本文件不预填项目链接或核对结论。

官方说明：[导入文件](https://pixso.cn/help/guide/8/1660225022876517/)、[导出文件](https://pixso.cn/help/guide/8/1660225022876746/)。
